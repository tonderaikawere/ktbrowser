# Security Policy & Vulnerability Disclosure

## 🛡️ Our Commitment

At **Kawerify Tech**, security and user privacy are foundational. **KT Browser** features local sandbox isolation, Do-Not-Track headers, zero third-party telemetry, and built-in ad/tracker blocklists.

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability in **KT Browser**, please report it immediately:

- **Email**: [security@kawerifytech.com](mailto:security@kawerifytech.com)
- **Website**: [https://kawerifytech.com/security](https://kawerifytech.com)
- **Response Time**: We acknowledge reports within 24 hours and aim to release patches within 7 business days.

Please do **NOT** open public GitHub issues for security vulnerabilities until we have verified and patched the issue.

Thank you for helping keep **KT Browser** secure for everyone!
